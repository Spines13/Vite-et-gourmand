Vite & Gourmand

Documentation de gestion de projet

Méthodologie

Le projet a été mené selon une démarche itérative inspirée de l'agilité : le besoin a d'abord été découpé en fonctionnalités autonomes et priorisées par dépendance technique (une fonctionnalité n'est démarrée que lorsque celles dont elle dépend sont terminées et validées), chaque fonctionnalité étant développée, testée puis intégrée avant de passer à la suivante plutôt que de tout développer en parallèle sans jalon de validation.

Cycle appliqué à chaque fonctionnalité

  1. Création d'une branche feature/<nom> depuis developpement.
  2. Développement (modèles d'accès aux données, règles métier, interface).
  3. Tests fonctionnels manuels de bout en bout (création de données réelles, vérification en base de données, nettoyage post-test).
  4. Fusion dans developpement, puis, une fois un ensemble cohérent de fonctionnalités validé, fusion de developpement dans main.

L'historique Git constitue la trace de ce suivi (voir git log --graph sur le dépôt).

Outils

  • Versionning : Git, avec un modèle à trois niveaux de branches (main / developpement / feature/*) conforme aux exigences du cahier des charges.
  • Suivi des tâches : backlog structuré par fonctionnalité (voir page précédente), à reporter dans l'outil de gestion de projet choisi.
  • Tests : validation manuelle systématique de chaque fonctionnalité contre une base de données réelle avant fusion, plutôt qu'une simple relecture de code.
